# Liquidation Lab 0.3 — Windows-first research lab

Исследовательский инструмент на Python/Kivy для анализа импульса и продолжительной консолидации. **Не выставляет ордера, не подключает аккаунт биржи и не даёт рекомендаций по сделкам.**

## Что нового в версии 0.3

- **Воспроизведение истории свеча за свечой**: `|<`, `<`, `▶/II`, `>`, `>|`, скорость 1x/3x/8x и ползунок времени.
- **Объяснение каждого шага**: поиск импульса, боковик, прохождение фильтров, ожидаемый виртуальный вход, фиксация TP/SL. Разграничены момент сигнала (закрытие) и момент входа (открытие следующей свечи).
- **Японские свечи OHLC**, EMA20/EMA50, границы боковика, виртуальные входы/выходы и уровни TP/SL.
- **Единый движок** для реплея и бэктеста. Каждая свеча участвует один раз; при одновременном достижении TP и SL консервативно выбирается SL. Учитываются комиссии и проскальзывание, просадка считается по *mark-to-market* с открытой позицией.
- **История Bybit**: публичный V5 REST с пагинацией до 1000 свечей на страницу, 7/30/90 дней, 15/30/60/240 минут или день. Только завершённые свечи, хронологическая сортировка и дедупликация.
- Экспорт/импорт OHLC CSV, 20+ офлайн-тестов, Windows/Linux CI.

## Запуск на Windows

Установи Python 3.11 или 3.12 (при установке активируй `Add Python to PATH`). В распакованной папке:

```powershell
py -m pip install -r requirements.txt
py main.py
```

`requirements.txt` содержит Kivy. Установочный EXE ещё не собирался; APK в этой ветке тоже не собран.

Для тестов без Kivy:

```powershell
py -m unittest discover -s tests -v
py -m lab.cli --scenario down --backtest
```

## Как пользоваться

1. Запусти `main.py`. Выбери «Демо: рост/снижение/боковик» или «Bybit BTCUSDT» и нажми «ЗАГРУЗИТЬ».
2. Используй `|<`, `<`, `▶`, `>`, `>|`, скорость и ползунок. График **не показывает будущих свечей**. Под графиком — последние закрытые виртуальные сделки, над ними объяснение текущего шага.
3. Нажми «БЭКТЕСТ», чтобы получить долю прибыльных, доходность и максимальную просадку. Исследование не означает прибыльности на новых данных.
4. При необходимости сохрани/загрузи CSV с заголовком `timestamp,open,high,low,close,volume`, где timestamp — миллисекунды UTC, а даты возрастают.
5. Опционально введи ключ CoinGlass для **текущего** снимка карты. Ключ не сохраняется, а карта не используется в историческом бэктесте. Требуется соответствующая подписка.

## Ограничения

- Учебные кластеры вымышлены. События *уже произошедших* ликвидаций не эквивалентны прогнозным уровням. **Исторических снимков ликвидаций CoinGlass нет**, значит в бэктесте 0.3 не применяется настоящая историческая карта ликвидаций.
- При воспроизведении прошлого текущая карта скрыта; иначе была бы утечка будущей информации.
- OHLC-симулятор не моделирует точную последовательность тиков внутри свечи, funding, рыночный импакт, плечо, маржин-коллы, проскальзывание в зависимости от ликвидности, недоступные данные и реальное исполнение.
- Программа экспериментальная: результаты **не являются финансовым советом**.
