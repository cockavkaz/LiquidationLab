# Liquidation Lab 0.2

Исследовательское приложение для Android на Python/Kivy. Анализ свечей Bybit и учебных карт ликвидаций, EMA/RSI/ATR, модель импульса и боковика, воспроизведение и виртуальный бэктест. **Нет выставления реальных ордеров и хранения API-ключей.**

В репозиторий добавляются исходники и GitHub Actions для сборки debug APK. После успешной сборки APK будет доступен во вкладке **Actions → Build educational Android APK → Artifacts**.

Исходный учебный код включает скрипты в `lab/`, `main.py`, `buildozer.spec`, тесты `tests/` и подробную документацию.
