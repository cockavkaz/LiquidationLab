# Liquidation Lab 0.2 — Android / Python

Исследовательское приложение с интерфейсом Kivy для анализа учебных и публичных рыночных данных. **Никаких реальных сделок и ордеров.**

## Функции
- Искусственные воспроизводимые OHLC-сценарии и условные кластеры ликвидаций.
- Публичные завершённые свечи BTCUSDT с Bybit REST.
- Необязательная текущая карта CoinGlass через официальный платный API (ключ используется только в оперативной памяти).
- EMA20/EMA50, RSI14, ATR14; импульс до боковика (окна не пересекаются).
- Виртуальный бэктест с комиссией/проскальзыванием, stop-first при неоднозначной свече.
- **Карта текущих ликвидаций CoinGlass не используется в историческом бэктесте.**

## Использование
На компьютере: `pip install -r requirements.txt && python main.py`. Тесты: `python -m unittest discover -s tests -v`.

## Android APK
Вкладка **Actions → Build educational Android APK → последний запуск → Artifacts**. Установочный APK находится внутри скачанного ZIP-артефакта, если сборка прошла успешно. Локально: `buildozer android debug` на Linux/WSL.

## Ограничения
Учебные кластеры — вымышленные, не позиции биржи. События уже исполненных ликвидаций не равны будущим уровням. Исторические результаты не предсказывают прибыль; отсутствуют funding, стакан, задержки и исполнение реальных ордеров. CoinGlass требует соответствующий тариф. API-ключи никогда не добавлять в GitHub.
