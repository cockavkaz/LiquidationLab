# Liquidation Lab 0.4 — независимая проверка истории (Windows)

Рабочая версия 0.3 остаётся в ветке `feature/replay-v0.3`. Эта версия добавляет **строго хронологическую** проверку стратегии без реальных ордеров и без исторических карт ликвидаций.

## Новый экран проверки

После загрузки Bybit или CSV нажми **TRAIN / HOLDOUT**. Отчёт делит свечи на 70% TRAIN и 30% HOLDOUT; вариант алгоритма выбирается исключительно на TRAIN. На HOLDOUT капитал и индикаторы сбрасываются, период прогрева не используется для сделок. Показываются результаты отдельно, включая виртуальную просадку по закрытиям свечей, комиссии и проскальзывание. Кнопка **ЭКСПОРТ JSON + CSV** сохранит исходные свечи, результаты, кривую капитала, закрытые виртуальные сделки и объяснения решений в `reports/validation-<UTC>`.

**Примечание:** если сделок мало, или результат неустойчив при изменении периода, никакой статистической значимости не заявляется. Применяются только OHLC свечи, а не история кластеров CoinGlass.

## Командная строка Windows

```powershell
py -m pip install -r requirements.txt
py main.py
# Реальная история 90 дней, 60 минут, выгрузка полного отчёта
py -m lab.validate_cli --bybit --symbol BTCUSDT --interval 60 --days 90 --output reports
# Проверка собственных свечей без интернета
py -m lab.validate_cli --csv data/bybit_history.csv --output reports
# Только тест работы программы на искусственных данных
py -m lab.validate_cli --demo down --output reports
py -m unittest discover -s tests -v
```

История Bybit загружается с публичного REST V5 без ключа. Свеча считается завершённой только после полного интервала. Программа не выставляет реальные ордера.

## Отличия от 0.3

- Разделение TRAIN/HOLDOUT с выбором из четырёх фиксированных параметрических вариантов исключительно по TRAIN.
- Контроль выбранного варианта относительно базового алгоритма на ранее неиспользованном HOLDOUT.
- Аналитика: virtual PnL, процент прибыльных, Profit Factor, серии убытков, комиссии, время в позициях, max DD по close-to-close mark-to-market.
- Аудит: CSV каждой закрытой сделки (включая дату виртуального сигнала), каждой свечи с RSI/EMA/ATR и объяснением решения, всей кривой капитала; JSON с предпосылками и качеством исходных данных.
- Проверка дубликатов/нечисловых свечей и разрывов истории без выдуманного заполнения данных.

## Что остаётся ограничением

1. Если источником служат **синтетические** свечи, результаты нельзя переносить на реальные рынки.
2. Исторические Liquidation Map CoinGlass недоступны в этой версии. Свежая карта не подмешивается в исторический тест.
3. Конец TRAIN и начало HOLDOUT разделены, так что первая часть HOLDOUT используется для прогрева индикаторов; капиталы и открытые позиции не пересекают границу.
4. Отсутствуют funding, спред стакана, рыночное воздействие, внутрисвечной порядок событий, динамические комиссии; результат не доказывает прибыльность.
5. Это Python/Kivy-приложение, не EXE; Android APK по-прежнему отдельно.

# Liquidation Lab 0.3 — Windows-first research lab

Исследовательский инструмент на Python/Kivy для анализа импульса и продолжительной консолидации. **Не выставляет ордера, не подключает аккаунт биржи и не даёт рекомендаций по сделкам.**

## Что нового в версии 0.3

- **Воспроизведение истории свеча за свечой**: `|<`, `<`, `▶/II`, `>`, `>|`, скорость 1x/3x/8x и ползунок времени.
- **Объяснение каждого шага**: поиск импульса, боковик, прохождение фильтров, ожидаемый виртуальный вход, фиксация TP/SL. Разграничены момент сигнала (закрытие) и момент входа (открытие следующей свечи).
- **Японские свечи OHLC**, EMA20/EMA50, границы боковика, виртуальные входы/выходы и уровни TP/SL.
- **Единый движок** для реплея и бэктеста. Каждая свеча участвует один раз; при одновременном достижении TP и SL консервативно выбирается SL. Учитываются комиссии и проскальзывание, просадка считается по *mark-to-market* с открытой позицией.
- **История Bybit**: публичный V5 REST с пагинацией до 1000 свечей на страницу, 7/30/90 дней, 15/30/60/240 минут или день. Только завершённые свечи, хронологическая сортировка и дедупликация.
- Экспорт/импорт OHLC CSV, 20+ офлайн-тестов, Windows/Linux CI.

## Запуск на Windows

Установи Python 3.11 или 3.12 (при установке активируй `Add Python to PATH`). В распакованной папке:

```powershell
py -m pip install -r requirements.txt
py main.py
```

`requirements.txt` содержит Kivy. Установочный EXE ещё не собирался; APK в этой ветке тоже не собран.

Для тестов без Kivy:

```powershell
py -m unittest discover -s tests -v
py -m lab.cli --scenario down --backtest
```

## Как пользоваться

1. Запусти `main.py`. Выбери «Демо: рост/снижение/боковик» или «Bybit BTCUSDT» и нажми «ЗАГРУЗИТЬ».
2. Используй `|<`, `<`, `▶`, `>`, `>|`, скорость и ползунок. График **не показывает будущих свечей**. Под графиком — последние закрытые виртуальные сделки, над ними объяснение текущего шага.
3. Нажми «БЭКТЕСТ», чтобы получить долю прибыльных, доходность и максимальную просадку. Исследование не означает прибыльности на новых данных.
4. При необходимости сохрани/загрузи CSV с заголовком `timestamp,open,high,low,close,volume`, где timestamp — миллисекунды UTC, а даты возрастают.
5. Опционально введи ключ CoinGlass для **текущего** снимка карты. Ключ не сохраняется, а карта не используется в историческом бэктесте. Требуется соответствующая подписка.

## Ограничения

- Учебные кластеры вымышлены. События *уже произошедших* ликвидаций не эквивалентны прогнозным уровням. **Исторических снимков ликвидаций CoinGlass нет**, значит в бэктесте 0.3 не применяется настоящая историческая карта ликвидаций.
- При воспроизведении прошлого текущая карта скрыта; иначе была бы утечка будущей информации.
- OHLC-симулятор не моделирует точную последовательность тиков внутри свечи, funding, рыночный импакт, плечо, маржин-коллы, проскальзывание в зависимости от ликвидности, недоступные данные и реальное исполнение.
- Программа экспериментальная: результаты **не являются финансовым советом**.

Техническая справка: [Bybit Get Kline](https://bybit-exchange.github.io/docs/v5/market/kline).
